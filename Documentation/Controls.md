# Controls
## On foot
| Action | Key |
|---|---|
| Move / look | W A S D / Mouse |
| Jump / sprint / crouch | Space / Shift (uses energy) / Ctrl or C |
| Multitool: mine ore, fight (uses energy) | Left mouse (hold) |
| Scan | T |
| Interact (talk, board ship, examine ruins, dismantle) | F |
| Build mode | B (wheel: change piece, R: rotate, left mouse: place) |
## Ship
| Action | Key |
|---|---|
| Thrust / reverse, strafe | W S, A D |
| Up / down | Space / Ctrl |
| Pitch, yaw / roll | Mouse / Q E |
| Boost (uses energy) | Shift |
| Refuel from cargo | R |
| Cockpit / chase camera | V |
| Exit (landed or nearly stopped) | F |
## Menus
Tab inventory and tabs, M galaxy map, J missions, Esc pause, F5 quick save, F9 quick load.
## Console (~)
`SEPlanets`, `SEGalaxy`, `SETravel <system> <planet>`, `SEGive <item> <n>`, `SEResearch <n>`, `SECredits <n>`, `SETime <hour>`, `SESave <slot>`, `SELoad <slot>`.
